FIELD NOTES

How to play

Each round shows either a skeletal formula or an English IUPAC name with fewer than ten carbon atoms. Choose the matching name or skeleton from the four or five options, then read the one-line naming rule. Both directions feed the same score. Use Share under the choices to send the exact question as a challenge link.

Priority first

Rank every functional group from the ladder below. Only the highest-priority group is named as the suffix; the rest become prefixes.

Numbering

Number the parent chain from the end that gives the principal group, then the substituents, the lowest locants.

Two directions

Structure → Name asks for the IUPAC name. Name → Structure asks you to pick the matching skeleton. Options are always real molecules from the bank.

Keyboard

A–E select an option. Enter moves to the next molecule after answering.
